# NexaERP Documentation

This directory contains system specifications, architectural designs, API definitions, and operational guides for **NexaERP — Mini ERP + CRM Operations Portal**.

## Project Overview
- **Frontend**: React, TypeScript, Vite, Tailwind CSS
- **Backend**: Node.js, TypeScript, Express.js
- **Database**: PostgreSQL with Prisma (to be connected in subsequent phases)

## Directory Structure
- `client/`: Single Page Application (SPA) frontend portal
- `server/`: RESTful API backend service
- `docs/`: System documentation and architectural diagrams
- `postman/`: Postman API collections and environments
